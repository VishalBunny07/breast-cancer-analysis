# data-analysis-and-visualization-on-breast-cancer-using-python
This repository contains a full data analysis and visualization project in Python based on the Breast Cancer Wisconsin (Diagnostic) Dataset. The objective of this project is to clean, visualize, and explore the dataset in order to discover insights that can help understand which features may contribute to breast cancer diagnoses.

This project is perfect for students, data people, and prospective data scientists who desire to work with live medical data and basic data science tools in Python.

Dataset Description
The Breast Cancer Wisconsin dataset has features derived from digitized images of fine needle aspirates (FNA) of breast masses. The features are used to describe the characteristics of the cell nuclei within the image. The dataset consists of:

Diagnosis (target): Malignant or Benign

30 Numerical Attributes: Mean, standard error, and worst values for properties such as radius, texture, perimeter, area, smoothness, etc.

Tools & Libraries
Python 3
Pandas – Data manipulation and cleaning
NumPy – Math operations
Matplotlib – Data visualization (2D plots)
Seaborn – Statistical graphics
Scikit-learn – Preprocessing and model-ready features
Jupyter Notebook – Interactive exploration and presentation
